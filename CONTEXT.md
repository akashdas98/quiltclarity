# Quilter Context

## Project Brief

QuiltClarity is a static-first quilting utility: external cut requirements plus
exact project-local stock produce one reconciled purchase-and-cut plan, optional
stock-independent pattern comparison, and eleven standalone calculators.

gaps, approvals/issues, and routed detail on demand. The queue does not authorize
