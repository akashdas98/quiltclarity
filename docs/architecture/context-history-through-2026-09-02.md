# Quilter Context

## Project Brief

QuiltClarity is a static-first quilting utility website. V1.1 turns an external project cut list plus exact project-local fabric stock into a jointly reconciled shopping-and-cutting plan, with optional pattern/fresh-fabric comparison and eleven standalone calculators.

The authoritative core package is `docs/v1.1/`; its Golden Rules lock domain
behavior and fixtures G01-G45. `docs/v1.1_GUIDES_HELP/` governs the post-M10
Guides/help checkpoint subject to the owner-validation substitution. The older
`docs/product/quilt_FINAL_*` package is historical V1 baseline evidence.

## Hard Boundaries

- Astro static-first; TypeScript domain engine; minimal client JavaScript.
- React is limited to one planner island when justified.
- No application backend, database, authentication, server persistence, runtime calculation service, or AI in V1.1.
- `localStorage` is the only V1 project persistence mechanism; the independent site-theme preference may also use it without containing project data.
- Golden domain rules override conflicting domain statements in other documents.
- Calculations and optimizer selection are deterministic and inspectable.
- SVG diagrams project optimizer geometry; they do not recompute layouts.
- The bounded optimizer favors practical quilting cuts and does not promise a global optimum.
- Each milestone must pass its tests, definition of done, and divergence review before the next begins.
