# V1.1 Calculator Domain Expansion

## Decision

Add Batting, QST, Flying Geese, and Pieces from Fabric as framework-independent contracts under `src/lib/domain/calculators`.

Batting returns the required overage rectangle plus every valid supplied-roll orientation. When neither orientation fits, it returns the still-valid required rectangle, no roll candidate, and explicit guidance that piecing is outside scope.

QST implements only the classic two-color hourglass batch and exposes both Standard and Trim-friendly starting-square sizes. Flying Geese implements only conventional 2:1 finished units and exposes both sizing modes for one-at-a-time and four-at-a-time methods; non-2:1 input is a blocking validation error.

Pieces from Fabric normalizes cut/finished dimensions through the shared domain normalizer and obtains maximum practical yield, requested-fit status, placements, and leftovers from the M2 finite-stock optimizer. It does not contain a grid or packing implementation of its own.

Finite-stock geometry comparisons use a narrowly scaled `1e-9` tolerance, and effectively zero split/area remainders are clamped to zero. This handles mathematically equal inch-to-millimetre boundaries without rounding or changing the authoritative source dimensions.

## Rationale

The Golden Rules lock the sizing and batch formulas, so separate UI arithmetic would create an avoidable divergence risk. Returning both sizing modes from one calculation keeps explanations and selected values derived from one result.

Batting width failures still have a useful required-size answer, but creating a pieced layout would exceed scope. Pieces from Fabric is the public repeated-stock projection of the same physical-bin behavior used by project reconciliation and must therefore share its engine.

The finished 6-inch pieces in a 12-inch stock regression exposed binary floating-point representations of mathematically equal converted lengths. A comparison tolerance at the geometry boundary corrects the violated equality invariant without quantizing stored millimetres.

## Consequences

- G41-G45 have one typed calculation source and explanation-ready outputs.
- QST and Flying Geese never underproduce the requested batch quantity.
- Flying Geese does not silently coerce proportions, and Batting does not synthesize piecing.
- Pieces from Fabric inherits bounded candidate generation, bin identity, orientation constraints, leftovers, determinism, and performance limits from finite-stock planning.
- M4 adds domain contracts only; routes, forms, analytics wiring, and calculator navigation remain scheduled for later milestones.
