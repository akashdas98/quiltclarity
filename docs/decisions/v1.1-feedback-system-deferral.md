# Feedback System deferral to V2

**Date:** 2026-09-30  
**Status:** Approved by the owner in this session

## Decision

Before continuation-document reconciliation, replace the current correction-report
page with an honest static “Feedback system coming soon” page. Preserve
`/corrections/` so existing links continue to work, and label its navigation
entry “Feedback”. Provide useful links to shipped Guides and methodology.

Owner-approved SEO follow-up: mark the coming-soon page `noindex` and exclude
it from the XML sitemap, preserving the URL, footer link, and crawler access.
Reassess indexing when the working Feedback System ships. This supersedes the
older trust-route indexing expectation for this one route.

The page accepts no submissions and offers no configured email endpoint, signup,
or promised delivery date. Remove `PUBLIC_CORRECTIONS_EMAIL` from current
deployment instructions and configuration examples. A monitored feedback inbox
is no longer a V1.1 launch dependency.

Record **Feedback System** as a planned V2 milestone in
`../v2/feedback-system-milestone.md`. Recording the milestone does not authorize
implementation, select a service, or expand V1.1's static architecture.

## Rationale

The owner requested a clear coming-soon page in place of the existing reporting
instructions and explicitly moved the Feedback System to V2. Recording the
shipped availability before document reconciliation prevents the launch workflow
from requiring a collection channel that V1.1 no longer offers.

## Consequences

This owner instruction supersedes the active correction-channel requirement in
the older static-content decision and launch checklist. Calculation correctness,
regression coverage, analytics privacy, and existing product acceptance remain
unchanged. Other identity, hosting, legal, and public-origin dependencies remain.

After the page and milestone are verified and checkpointed, resume the queued
domain, brand, and continuation-document reconciliation against this baseline.

## Acceptance

- The retained route renders the unavailable state in static HTML.
- Its static robots metadata includes `noindex`, and the sitemap omits the route.
- Navigation and About copy accurately describe Feedback availability.
- No report form, email link, or submission endpoint is offered.
- The page remains readable and usable on mobile, desktop, and without JavaScript.
- The V2 milestone and current launch/configuration records agree with the deferral.
