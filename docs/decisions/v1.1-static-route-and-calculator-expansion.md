# V1.1 Static Route and Calculator Expansion

## Status

Accepted in V1.1 M7 on 2026-08-21.

## Context

The V1 static site already had seven calculators, five guides, three trust routes, configurable canonicals, and an explicit sitemap. V1.1 adds four completed calculator domain contracts and a broader launch-quality route map. The existing planner URL is established throughout persistence, content, tests, and launch materials, while the migration plan explicitly permits retaining it to avoid needless redirect risk.

## Rationale

Each new route must provide a complete static task explanation before JavaScript, while calculation remains in the shared typed domain. Hand-authored decision-based links create a coherent acquisition surface without numeric/permutation pages. Retaining `/fabric-cutting-planner/` avoids a hosting-specific redirect dependency; route naming is less important than canonical consistency and product behavior.

## Decision

- Keep `/fabric-cutting-planner/` as the self-canonical planner route, use **Fabric Cutting Planner** as its visible tool label, and update its title, proposition, stock explanation, pattern caveat, worked example, privacy statement, and optimizer disclosure. Do not create `/project-planner/` unless a deployment can provide a real permanent redirect.
- Add static interactive routes for Quilt Batting, QST, Flying Geese, and Pieces from Fabric. Their controllers call the M4 domain contracts; formulas remain out of Astro and browser controllers.
- Pieces from Fabric projects the domain-selected finite-stock placements through the shared presentation/SVG layer and includes a textual equivalent. Presentation never packs again.
- Expand the calculator allow-list to the eleven fixed identifiers. Analytics event shapes remain closed and contain no input values or free text.
- Publish the V1.1 guide index, ten canonical hand-authored guide tasks, and How It Works page. Retain the two prior guide URLs as `noindex` canonical aliases to their replacement routes because static hosting cannot guarantee redirects.
- Publish exactly 29 indexable routes in the explicit sitemap: the retained product surface, eleven calculators, ten guides plus guide index, How It Works, and three trust routes. Do not index user states, query variants, or mass-generated pages.

## Consequences

- Static builds contain 29 indexable routes, two non-indexable canonical guide aliases, and the custom 404.
- The calculator index, homepage, navigation, related links, metadata, canonicals, sitemap, and browser route audit share the same current surface.
- M8 can expand the closed V1.1 event taxonomy without revisiting route or calculator calculation architecture.
