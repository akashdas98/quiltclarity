# V1.1 M9 Guided Manual Validation

## Purpose

This is the complete operator-led manual test for V1.1 M9. It is designed for
a human test operator who does not need quilting expertise. The operator follows
exact actions, checks deterministic oracles, and supplies human judgment for
visual hierarchy, readability, interaction feedback, keyboard use, responsive
layout, and print output.

This protocol was originally designed to complement
`v1.1-m9-usability-gate.md`. After eligible target quilters proved unavailable,
the user explicitly accepted the completed redesign and this exhaustive guided
suite as the practical M9 substitute. It still does not prove unassisted
target-user comprehension; that limitation is recorded in
`../decisions/v1.1-m9-validation-substitution.md`.

## Result model

Record each check as `PASS`, `FAIL`, or `BLOCKED`.

- `P0`: data loss, unsafe output, materially incorrect purchase/cutting result,
  or a placement that cannot be executed.
- `P1`: a core workflow cannot be completed, a result concept is contradictory,
  or content is inaccessible at a required viewport/input mode.
- `P2`: meaningful friction, misleading hierarchy, clipping, or degraded but
  recoverable behavior.
- `P3`: cosmetic issue with no material effect on comprehension or execution.

The guided manual validation passes only when every deterministic oracle passes,
no P0/P1 issue remains, and every required human-judgment check is completed.
Failures must record the check ID, actual behavior, expected behavior, browser,
viewport, and screenshot path where visual evidence matters.
